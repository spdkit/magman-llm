# Dataset Documentation

This folder provides the datasets used by the manuscript and SI analyses.

## benchmark_dataset.csv
- Ground-truth benchmark summary for 907 VASP jobs.
- Key fields: `filepath`, `label`, `num_steps`.

## 02_main_data
- Data used for main-text and SI model/prompt comparison at fixed 50-step inputs.

## 03_integrated_workflow_data
- Data used for integrated workflow evaluation and resource-saving analysis.
- Includes runs corresponding to Few-shot_2 and Few-shot_3 workflow settings.

## 04_rule_based_evaluator_data
- Data used for the rule-based baseline comparison.
